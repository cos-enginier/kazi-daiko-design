# 余白｜家事代行サービス トップページ

小規模な家事代行事業を想定した、静的なトップページの制作デモです。HTML・CSS・JavaScriptとローカルSVGのみで構成し、ビルドやパッケージのインストールは不要です。

## プレビュー

```sh
npm run dev
```

Python 3 が必要です。起動後、 http://127.0.0.1:4173 を開きます。`index.html` を直接ブラウザで開くこともできます。

## 実装内容

- スマートフォン・PC対応のトップページ
- サービス紹介（掃除・洗濯・片付け・料理）、単発／定期の参考料金、利用の流れ
- 開閉式FAQ、モバイルメニュー、プランに応じた相談案内ダイアログ
- オリジナルのSVGイラストとロゴ。外部フォント・画像・解析・ライブラリへの通信なし
- 制作デモ表示と検索エンジン向け noindex

## 公開前に確定すること

「余白」は仮称です。価格、最低利用時間、交通費、サービス内容、対応エリア、営業時間、キャンセル規定はデモの設定で、実事業の条件ではありません。実績・口コミ・資格・保険加入など、未確認の実績や保証は掲載していません。

相談ボタンは案内表示のみです。個人情報の収集・送信、予約確定、オンライン決済、LINE／L Messageの実接続はありません。正式なLINE導線を接続する場合は `script.js` の相談処理を実URLへの遷移に変更してください。正式公開時は運営者情報・必要な規約等を整え、noindex を見直してください。
